# Owners: which agent owns which path

Every tracked source file under `api/`, `web/` and `acceptance/` has exactly one
owner. `api/tests/guards/test_ownership.py` fails if a file matches no row or two
rows, so a new folder forces a decision here.

- **Source** means `*.py`, `*.ts`, `*.tsx`, `*.mjs`, `*.js`, `*.sql`, `*.sh`. Not
  source: `node_modules`, `__pycache__`, `openapi*.json`, assets, docs and config.
- **Row format:** `` `glob`, `glob`, `!excluded` | owner ``. `*` stays in one folder,
  `**` crosses folders, `{a,b}` expands, `!glob` removes files from the row.
- **Admin screens follow their area** (`admin/vendors` is vendors-owner), so one owner
  sees a feature from route to screen. The console shell is platform-owner's.
- **A test follows its subject** (`test_payments_*` is money-owner). Shared test
  infrastructure, guards, migrations and the acceptance harness are platform-owner's.
- **Money inside bookings is money-owner's**: the financial, cancellation-split, policy,
  payment and receipt files of `bookings/`. The request lifecycle is bookings-owner's.
- Where two areas touch one file, the owner is the one whose rule file names it
  (`.claude/rules/`).
