# Lesson spin-offs

**How to take a lesson**

1. Open a **new Cursor chat** (keep the curriculum chat as your map).
2. Open the file for the day you want (e.g. `day-01.md`).
3. Copy everything inside the ` ``` ` block under **Spin-off prompt**.
4. Paste into the new chat and send.

When you finish a day, update `docs/engineering/PROGRESS.md` in that chat or here.
